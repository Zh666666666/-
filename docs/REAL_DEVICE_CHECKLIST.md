# 真机联调操作清单（Android 网关 → 网站 → AI）

适用版本：含 `auto-analyze samples and align WitMotion APK keys` 之后的 APK / 后端。

目标闭环：

1. 手机连接 WT9011DCL-BT50
2. 采集并上传到 `https://www.dorianaistudio.cloud`
3. 服务端自动生成 AI 分析建议

---

## 0. 开始前准备

| 项 | 要求 |
| --- | --- |
| 手机 | Android 7.0+，已开蓝牙与定位 |
| 传感器 | 至少 1 只 WT9011DCL-BT50；做膝角建议 2 只 |
| 电量 | 传感器有电，按键后指示灯可闪 |
| 网络 | 手机可访问目标网站 |
| 平台地址 | `https://www.dorianaistudio.cloud` |
| 患者 ID | Demo 可用 `demo-patient-1`；真实库用平台患者真实 ID |
| APK | 使用包含本次修复的构建（电量/广播名/HARDWARE/自动 AI） |

说明：

- **单传感器**：可上传原始姿态数据，但通常**不会**生成屈曲角记录，也就**不会**自动 AI。
- **双传感器**（大腿 + 小腿）：可计算 `flexionAngle`，才会生成康复记录并自动 AI。

---

## 1. 安装与启动

1. 安装最新 Debug/Release APK。
2. 打开应用，确认首屏可停留（不是秒退）。
3. 点 **运行安装自检**。
4. 确认以下为通过/可用：
   - BLE 硬件
   - 蓝牙开关
   - 权限
   - 定位服务
   - 加密离线队列
   - 平台配置输入区

失败时：按页面提示开蓝牙/定位/权限，再重跑自检。

---

## 2. 填写平台配置

1. **平台 HTTPS 地址**  
   `https://www.dorianaistudio.cloud`
2. **患者 ID**  
   先用 `demo-patient-1` 做通路验证。
3. **Bearer Token**  
   当前后端若未强制鉴权可留空；以后启用鉴权再填。
4. 点 **开始采集**。
5. 状态应类似：  
   `采集已启动...` / `采集会话已就绪...`

---

## 3. 扫描并连接传感器

1. 点 **授权并扫描 WT 设备**。
2. 首次允许蓝牙、附近设备、定位权限。
3. 传感器开机，确认列表出现 `WT...` 广播名（例如 `WT901BLE...`）。
4. 连接分配：
   - 一只 → **大腿 (THIGH)**
   - 另一只 → **小腿 (SHANK)**
5. 等连接状态变为已连接。
6. 肢体伸直后分别点：
   - **大腿归零**
   - **小腿归零**

### 成功信号
- 扫描列表有设备
- 连接后运行信息持续更新
- 未反复报权限/定位错误

### 常见失败
| 现象 | 处理 |
| --- | --- |
| 扫不到 | 传感器重新开机；靠近手机；确认官方 App 也能扫到 |
| 秒断 | 只连本 App，关掉官方 App；减少蓝牙干扰 |
| 权限失败 | 系统设置里手动打开蓝牙/定位/附近设备权限 |

---

## 4. 采集与上传

1. 慢速做屈伸动作 20–60 秒。
2. 看运行信息是否出现：  
   `已上传 N 条真实网关采样。`
3. 若显示“上传暂缓...队列中有 N 条”：
   - 检查手机网络
   - 检查平台地址是否可访问
   - 等 15 秒自动重试

### 断网补传抽查（建议做一次）
1. 开飞行模式，采集 10–20 秒。
2. 恢复网络，等待约 15 秒。
3. 确认队列被上传清空。

---

## 5. 网站侧验证

浏览器打开：

1. `https://www.dorianaistudio.cloud/login`
2. 进入护士端或家属端仪表盘
3. 检查是否出现新数据：
   - 最新屈曲角/活动数据
   - 来源尽量为 **HARDWARE**（不是 DEMO）
   - 设备列表/绑定有对应传感器
4. 检查是否出现 **AI 分析报告**  
   - 有屈曲角记录后应自动出现
   - 无真实 Key 时 `provider` 可能是 `local-rule`
   - 配好 Key 后应为 `openai` 或 `anthropic`

### 接口快速自查（可选）

```bash
# 仪表盘
curl -sS "https://www.dorianaistudio.cloud/api/dashboard" | head -c 500

# 手动补一次 AI（patientId 换成实际值）
curl -sS -X POST "https://www.dorianaistudio.cloud/api/ai-analyses" \
  -H "Content-Type: application/json" \
  -d "{\"patientId\":\"demo-patient-1\"}"
```

注意：

- 若 dashboard 仍只有演示患者且不随上传变化，说明线上可能仍是 **Demo 内存模式**，需要配置真实 `DATABASE_URL`。
- 自动 AI 只在**生成了膝角记录**时触发；仅原始姿态、无 `flexionAngle` 不会自动分析。

---

## 6. 判定表

| 检查项 | 通过标准 |
| --- | --- |
| App 启动 | 可打开，自检可跑 |
| 扫描连接 | 发现 `WT*` 并可分配大腿/小腿 |
| 本地采集 | 运行信息有数据更新 |
| 上传 | 出现“已上传 N 条” |
| 网站数据 | 仪表盘出现新 HARDWARE 记录 |
| 自动 AI | 有分析报告/建议；无 Key 时 local-rule 也可接受 |
| 真实 AI | 配置 Key 后 provider 变为模型服务商 |

---

## 8. 当前已知边界

- 线上若未接真实数据库，数据可能只在 Demo 层展示，重启后不保留。
- 未配置 AI Key 时，分析是规则引擎，不是大模型。
- 单传感器通常不足以触发膝角 + 自动 AI。
- `BLE-...` 只是网关标识，不是厂商序列号。
- 首版以前台采集为主，长时间息屏会话还不稳定。

---

## 9. 最短成功路径（5 分钟版）

1. 打开 App → 自检通过  
2. 填 `https://www.dorianaistudio.cloud` + `demo-patient-1`  
3. 开始采集  
4. 扫描并连接大腿 + 小腿  
5. 归零 → 屈伸 30 秒  
6. 看到“已上传 N 条”  
7. 网站护士端看到新数据 + AI 建议
