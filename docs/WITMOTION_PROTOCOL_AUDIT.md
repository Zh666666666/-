Last reviewed: 2026-07-12

本文件对照仓库内 `docs/WITMOTION_WT9011DCL_BT50_REFERENCE.md`、官方 WitSDK 源码与
当前 Android 网关实现，记录：

1. 当前 APK/网关与官方协议的偏差
2. 已修复项
3. 官方文档中可直接正向作用于本项目的信息与方法

## 1. 官方协议 / SDK 关键事实

| 主题 | 官方事实 | 项目影响 |
| --- | --- | --- |
| 默认姿态帧 | `0x55 0x61` + 加速度/角速度/欧拉角，小端 int16 | 真机抓包校验应使用该布局 |
| 缩放 | Acc `/32768*16`；Gyro `/32768*2000`；Angle `/32768*180` | 官方 SDK 已完成缩放，应用层不要二次缩放 |
| SDK 数值键 | `AccX/Y/Z`、`AsX/Y/Z`、`AngX/Y/Z`、`Electricity` | 生产路径必须读这些键，而不是显示字符串 |
| 显示标签 | 展示文本可能写 `AngleX` | 不能把显示标签当 `GetData` 键名 |
| 扫描过滤 | 广播名以 `WT` 开头 | 与当前扫描逻辑一致 |
| 归零 | SDK `SetAngle0()` | 首版保持 SDK 调用，不发猜测写命令 |
| 输出频率 | 默认 10 Hz，可到 50–200 Hz | 当前 App 限流 10 Hz（100 ms）符合默认基线 |
| 电量 | 寄存器/回调 `Electricity` | 应随样本上传，供设备状态与预警 |
| 位置模式 | 寄存器 `0x96=1` 会去掉加速度/角速度 | 膝关节 ROM 首版禁用 |
| 坐标系 | 东北天，欧拉 Z-Y-X；pitch 限 ±90° | 膝角不能盲减任意欧拉轴；先同向安装 + 直腿归零 |

## 3. 官方方法中对本项目正向可用的内容

### 3.1 连接与采集流程（直接复用）
1. 开蓝牙与定位
2. 扫描 `WT*` 设备
3. 连接后确认加速度/角速度/角度实时变化
4. 安装后做直腿 `SetAngle0`
5. 以 SDK 数值键作为唯一生产数据源

### 3.2 数据契约（直接复用）
- 上传字段：`ax/ay/az`、`gx/gy/gz`、`roll/pitch/yaw`、`batteryLevel`、`raw`
- 来源字段：真实 SDK 样本 = `HARDWARE`；模拟器 = `DEMO`
- 膝角：双传感器相对 pitch（同向安装 + 归零后）作为首版 ROM 估计

### 3.3 安全边界（必须遵守）
- 不在生产路径发未验证的写寄存器命令
- 不启用位置模式做 ROM
- 不用绝对 yaw 做主膝角
- 不把广播名/MAC 当已验证出厂序列号

### 3.4 真机验收方法（直接复用）
- 官方 App 对照：同姿态下角度趋势一致
- 抓一份 `0x55 0x61` 原始通知，核对 SDK 键值缩放
- 断网采集 → 联网补传，确认加密队列清空且服务端 `source=HARDWARE`

## 4. 与 AI 分析闭环的关系

- 样本上传 API 在生成膝角记录后，会**自动触发** AI 分析（30 秒冷却，避免 10 Hz 刷爆）
- 无 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` 时回退本地规则分析
- 提示词会区分 `HARDWARE` 与 `DEMO`，便于后续真实采集分析与演示数据隔离
- 后台补真实 API Key 后，同一路径即可对真实上传数据出建议，无需再改上传链路

- **本次已修关键偏差**：电量、广播名、来源标记、Ang*/Angle* 兼容
- **仍待真机证明**：双传感器临床精度、原始帧旁路、序列号、后台保活
